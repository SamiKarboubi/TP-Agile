# Frontend React

L'interface de recherche de films utilise React et Vite. Consultez le [README principal](../README.md) pour la configuration de Claude, du MCP, de TMDB et d'OMDb.

```powershell
cd frontend
npm ci
npm run dev
```

Ouvrez <http://localhost:5173>. Le proxy Vite transmet `/api` au backend sur <http://localhost:8000>.

```powershell
npm run lint
npm run build
```
